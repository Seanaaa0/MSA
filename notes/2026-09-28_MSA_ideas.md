# MSA 研究想法整理 — 2026-09-28

## 1. 核心問題

目前 MSA（Model Shock Absorber）最核心的研究問題不是：

> 「模型 / belief 到底對不對？」

而是：

> **「即使模型 / belief 有誤，它對眼前這個 decision 是否仍然足夠好？」**

也就是：

\[
	ext{Model Error} 
eq 	ext{Decision Inadequacy}
\]

同樣大小的 belief error，在不同位置、不同任務、不同候選 action、不同 local context 下，可能導致完全不同的 consequence。

因此 MSA 的核心可以描述成：

> **Decision-conditioned Adequacy：判斷目前不完美的 belief 是否足以支援即將執行的 decision。**

---

## 2. 目前建立的實驗架構

目前系統已經被拆成幾個清楚的部分：

```text
Reality / Environment
        ↓
Observation / True State
        ↓
Belief / Estimated State
        ↓
Planner
        ↓
Candidate Action
        ↓
Experiment-side Evaluator
```

目前主要模組：

```text
src/env.py
    真實 GridWorld / transition dynamics

src/maps.py
    simple / branch / detour / dead_end / corridor 等不同地圖

src/planner.py
    deterministic A* planner

src/episode.py
    perfect-information episode baseline

src/belief.py
    agent 的 estimated state

src/perturbation.py
    controlled belief error

src/evaluator.py
    experiment-side ground-truth consequence evaluator

experiments/run_sweep.py
    multi-map × multi-error sweep
```

這裡最重要的資訊隔離是：

### Agent side 可以看到
- belief
- goal
- candidate action
- 未來可能加入 uncertainty / support / local context

### Experiment side 才可以看到
- true state
- oracle action
- actual error
- actual regret
- ground-truth adequacy

未來 Adequacy Monitor 不能偷看 experiment-side ground truth。

---

## 3. 第一個問題：Action 不同不等於 Decision 壞掉

最初 evaluator 使用：

```text
oracle_action != agent_action
```

作為 inadequacy proxy。

但實驗發現：

```text
True state  = (4, 3)
Belief      = (6, 3)

Oracle      = DOWN
Agent       = RIGHT

Optimal cost      = 6
Agent action cost = 6
Decision regret   = 0
```

也就是：

\[
a_{oracle} 
eq a_{agent}
\]

但是：

\[
Q(s,a_{agent}) = V^*(s)
\]

因此 action 雖然不同，task consequence 完全沒有變差。

所以得到：

\[
oxed{	ext{Action Divergence} 
eq 	ext{Decision Inadequacy}}
\]

因此 evaluator 從「action equality」升級成「consequence / regret」。

---

## 4. Consequence-based Adequacy

目前 one-step evaluator 定義：

\[
V^*(s)
=
	ext{從 true state 到 goal 的 optimal cost}
\]

agent 根據 belief 選出 action \(a_b\)，然後從 true state 實際模擬這一步：

\[
Q^*(s,a_b)
=
1 + V^*(s')
\]

decision regret：

\[
R(s,a_b)
=
Q^*(s,a_b)-V^*(s)
\]

目前 V2 的最嚴格設定：

```text
regret = 0
→ adequate

regret > 0
→ inadequate
```

這仍然比較接近「optimality」，未來應該升級成 task tolerance：

\[
R(s,a) \le 	au
\]

或 normalized regret：

\[
R_{rel}
=
rac{R(s,a)}{\max(V^*(s),1)}
\]

也就是最後真正想處理的是：

> **不是一定要完美，而是要「good enough」。**

---

## 5. 第一輪固定 error experiment 的發現

固定：

\[
|\delta|_1 = 2
\]

可以同時得到：
- adequate decisions
- inadequate decisions

因此：

\[
oxed{
	ext{Error Magnitude Alone Is Insufficient}
}
\]

五歲版本：

> 兩個人都把自己的位置看錯兩格，一個仍然可以做對 decision，另一個卻會做出壞 decision。

所以不能只用：

```text
if error > threshold:
    replan
```

Adequacy 必須和：
- belief
- action
- goal
- local geometry
- task context

一起考慮。

---

## 6. 第二個問題：Inadequacy 一度退化成 Collision Detection

在最早的 simple map 中，positive regret 幾乎全部來自撞牆。

也就是近似：

\[
	ext{Inadequacy} pprox 	ext{Collision}
\]

如果一直這樣，MSA 就可能只是比較複雜的 collision detector。

因此加入 richer maps：
- branch
- detour
- dead-end-like structure
- corridor
- long / short route

目的不是單純增加難度，而是製造：

```text
belief 合法
action 合法
沒有 collision
仍然可以完成 task
BUT
decision consequence 變差
```

也就是：

\[
	ext{Safe} 
eq 	ext{Adequate}
\]

---

## 7. V2：Multi-map × Multi-error

目前已經跑：

```text
Maps:
- simple
- branch
- detour
- dead_end
- corridor

Error magnitudes:
0, 1, 2, 3, 4
```

V2 結果：

```text
Total cases:                10086
Valid beliefs:               4067
Invalid beliefs:             6019

Adequate valid decisions:    1991
Inadequate valid decisions:  2076

Non-collision inadequacies:   445
Collisions:                  1582
False terminals:               49

Mean regret:                0.615
Maximum regret:                 2
```

其中最重要的是：

```text
Non-collision inadequacies = 445
```

代表已經成功找到：

> **沒有撞牆，但 decision 仍然造成 task degradation 的案例。**

因此：

\[
oxed{
	ext{Decision Inadequacy Is Not Reducible To Collision}
}
\]

---

## 8. Multi-error 到底告訴我們什麼

在 valid beliefs 中，error magnitude 越大，平均 inadequacy 的比例會增加。

但更重要的是：

> **固定同一個 error magnitude，仍然同時存在 adequate 和 inadequate decisions。**

例如 error = 2 並不是：
- 全部 adequate
- 或全部 inadequate

而是兩種結果都大量存在。

因此目前真正 demonstrated 的現象是：

1. **Same error magnitude can produce both adequate and inadequate decisions.**
2. **Different actions do not necessarily imply different task quality.**
3. **Decision inadequacy can happen without collision.**

這些結果目前只是在 deterministic GridWorld setting 中的 principle demonstration，還不能宣稱已證明 MSA 對 Physical AI 有效。

---

## 9. Physical AI / 機械手臂的對應

把 GridWorld 換成機械手臂：

```text
true_state
=
真實 joint angles
真實 end-effector pose
物體真實位置
障礙物真實位置

belief
=
camera / encoder / estimator
認為上述東西的位置

action
=
move / grasp / rotate / insert / trajectory command

goal
=
抓取、插孔、搬運、操作物體
```

例如物體 localization error 都是 5 mm：

### Case A
- gripper 很寬
- 物體很大
- 周圍沒有障礙
- 5 mm error 對 grasp 沒影響

→ Adequate

### Case B
- 要做高精度 insertion
- socket tolerance 只有 1–2 mm

→ 同樣 5 mm error 可能完全不能接受

因此 Physical AI 版本的核心是：

> **不要問 world model 是否完美，而要問它是否足以支援「現在要執行的這個 action」。**

---

## 10. MSA 不只是 Trust / Replan 二選一

目前又出現一個新的想法：

> **Not every inadequacy requires full replanning.**

例如機械手臂抓取點只偏 5 mm：

```text
原 trajectory 大部分都正常
只有最後位置偏 5 mm
```

沒有必要：
- 全部 belief 丟掉
- 全部重新 perception
- 全部重新 planning

可能只需要：

```text
最後 local correction +5 mm
```

因此 intervention 可以分層：

```text
Level 0 — Trust
    直接 execute

Level 1 — Local Patch
    小幅 pose / waypoint / joint correction

Level 2 — Partial Replan
    保留大部分 trajectory，只重算局部

Level 3 — Full Replan
    重做 planning

Level 4 — Query Reality
    重新 sensing / localization / observation
```

這代表 MSA 未來可能不只是：

```text
Adequate / Inadequate
```

而是：

```text
Adequacy
    ↓
Required Intervention Level
```

---

## 11. Hard / Soft Adequacy

這也可以和先前「硬 + 軟」的想法結合。

### Hard constraints

例如：
- collision
- joint limit
- torque limit
- human safety
- false task completion
- belief outside physically possible support

違反就一定不能執行。

### Soft constraints

例如：
- 多走 3%
- trajectory 稍微變長
- grasp quality 稍微下降
- energy 稍微增加
- execution time 稍微增加

這些不一定值得 replan。

所以更完整的 adequacy 概念可能是：

```text
Hard validity
+
Soft task regret / tolerance
```

而不是單純 binary correctness。

---

## 12. Context / Correction Memory 想法

如果 local corrections 重複出現，例如：

```text
camera prediction:
x = 100 mm

actual:
x = 105 mm

residual:
+5 mm
```

而且之後多次都出現相同 residual，可以暫存：

```text
recent correction:
camera x bias ≈ +5 mm
```

讓後續 belief 做快速補償。

但這一層不能現在直接加，因為 correction 是否可重用本身又是一個新問題。

未來 correction memory 至少需要：
- context
- confidence
- age / decay
- validity condition
- source

因此它比較接近：

> **short-term online residual adaptation / calibration memory**

而不是單純聊天式 context memory。

## 13. 目前應該切住的研究邊界

目前碩論核心先保持：

\[
oxed{
	ext{Can an agent determine whether its imperfect belief is adequate for the current decision?}
}
\]

也就是：

> **Agent 在不知道 true state 的情況下，能不能在 action 執行前判斷自己的 belief 是否已經「夠用」？**

這是 MSA 第一核心。

下一層才是：

\[
oxed{
	ext{If inadequate, what is the minimum required intervention?}
}
\]

也就是：
- ignore
- local patch
- partial replan
- full replan
- QueryReality

再下一層才是：

\[
oxed{
	ext{Can previous corrections be reused?}
}
\]

也就是 short-term correction memory。

---

## 14. 現在還沒有完成的部分

目前還沒有真正做出 Adequacy Monitor。

現在的 evaluator 是「老師」，它知道：
- true state
- oracle action
- actual regret

它可以事後標記：

```text
adequate / inadequate
```

但真正 Agent 不知道答案。

因此下一個真正的研究問題是：

> **Agent-side 可以使用哪些資訊，在沒有 true state 的情況下預測 decision adequacy？**

候選資訊可能包含：
- belief
- uncertainty
- belief support
- candidate action
- goal
- local geometry
- alternative-action stability
- planner margin / decision sensitivity

這才是下一階段真正開始進入 MSA 本體的地方。

---

## 15. 目前研究脈絡一句話版

目前已經 demonstrated：

> **「model error 有多大」不是最重要的問題；真正重要的是這個 error 對眼前 decision 的 consequence 是否仍在可接受範圍。**

因此 MSA 最終想做的是：

```text
Imperfect Belief
        ↓
Candidate Decision
        ↓
Adequacy Monitor
        ↓
   ┌────┴────┐
   │         │
Trust    Intervention
             ↓
      minimal required repair
```

Physical AI 版本則可以理解成：

> **A physical agent should not ask whether its world model is perfectly correct, but whether the current model is sufficient for the action it is about to take.**
